# Lite-GD — Paper-aligned Reproduction Branch

Branch: `repro/paper-aligned-20260925`

This branch is an audit and reconstruction of the WWW 2024 / TMC 2025 Lite-GD method.  
The original `main` branch is intentionally left unchanged.

## Read this first

- [REPRO_AUDIT.md](REPRO_AUDIT.md) — implementation/data audit and the reproduction protocol.
- [REPRO_RESULTS_20260925.md](REPRO_RESULTS_20260925.md) — verified leakage-free and exact-label results.

Do **not** use the legacy `code/Lite-GD/train.py` / `val.py` result as reproduction evidence. The legacy path:

- is a PointerNet rather than the full paper model;
- uses the same archived tensor for training and validation;
- omits the published node/edge GCN pre-training, filters, distance/angle crossover and gating chain;
- was trained against a pickup-first search-space restriction that is narrower than the paper's pickup-before-own-dropoff constraint.

## Verified result so far

On the recovered 1,000-case simplified Chengdu tensor, after regenerating exact labels under the paper precedence rule and using a deterministic 8:1:1 split with three seeds:

| Model | Mean route gap |
|---|---:|
| Coord-only core | 8.04% |
| GCN-only core | 7.55% |
| Legacy 23D PointerNet, clean split | 5.55% |
| Domain crossover only | 5.15% |
| **GCN + distance/angle crossover + gating** | **4.68%** |

This is real held-out evidence for the core online Lite-GD design, but it is **not** a reproduction of the published Chengdu table: the retained dataset is 1,000 simplified cases rather than the paper's 10,000 edge+ratio benchmark, and exact-sequence accuracy is still much lower than reported in TMC.

## Exact-label reconstruction

The archived node-candidate labels are regenerated by:

`repro/relabel_exact_opt.py`

The older historical edge+ratio inputs are reconstructed and audited by:

- `repro/historical_chengdu.py`
- `repro/relabel_historical_exact.py`
- `repro/audit_historical_exact.py`

Under one unified point-on-edge directed metric, only 130/1,000 historical saved selected sequences remain exact-optimal; their mean gap to the regenerated paper-precedence optimum is 21.32%. Historical labels are therefore treated as development artifacts, not ground truth.

## Current reconstruction stages

1. **Strict baseline** — `repro/strict_pointer.py`
2. **Paper online core** — `repro/litegd_core.py`
3. **Exact node-candidate relabeling** — `repro/relabel_exact_opt.py`
4. **Historical edge+ratio exact relabeling** — `repro/relabel_historical_exact.py`
5. **Joint node/edge GCN + exact-route pre-training pilot** — `repro/historical_full_model.py`
6. Filters and final multi-seed validation are added only after pre-training is independently shown to help.

## Reproduction policy

A result is only promoted as evidence if it has:

- no train/test leakage;
- a fixed split and seed;
- exact or independently certified route labels;
- the paper pickup-before-own-dropoff rule;
- directed road-network evaluation;
- held-out test reporting;
- multi-seed confirmation for final comparisons.

See the audit/results documents for exact commits, caveats and experiment outputs.
